# ADR 0001: 采用 ADR 记录架构决策

- 状态: 已接受
- 日期: 2026-07-13

## 背景

VeriTool-RL 涉及多处会被面试追问的设计取舍 (课程顺序、奖励设计、是否上线在线 RL、模型尺寸等)。需要一种轻量、可追溯的方式记录「为什么这样设计、替代方案是什么」。

## 决策

采用 Architecture Decision Record (ADR) 记录重要决策, 每条一个文件, 编号递增, 存于 `docs/adr/`。

## 后果

- 面试时可直接引用决策记录回答追问;
- 决策变更时新增 ADR 而非静默修改历史。

## 模板

```
# ADR NNNN: 标题
- 状态: 提议 / 已接受 / 已废弃 / 被取代
- 日期: YYYY-MM-DD
## 背景
## 决策
## 后果
## 备选方案
```
