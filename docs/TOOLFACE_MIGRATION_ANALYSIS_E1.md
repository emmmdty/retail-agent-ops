# 宽工具面迁移分析（Phase E1，按简历项目质量定）

**日期**：2026-09-04
**性质**：书面建议。**本文档不迁移任何东西、不动 v3/v4 冻结契约**；是否迁移由用户裁决
（决策门 #6）。用户原话：「是否迁移到更宽工作面按照简历项目质量定」。

---

## 三个选项

- **选项 A（现状）**：发布闭环在 v1 口径（sft-008 合并形态，3 工具 / 6 场景 / 120 条
  封存 holdout）；v3（15 工具）与 v4（5 工具 / 12 场景）作为**探索性结论**存在，
  不进入发布判定。
- **选项 B**：rtc 第四轮修好后，把发布候选迁到 **v4 口径**（5 工具 / 12 场景）重走
  一次正式冻结与发布判定。
- **选项 C**：迁到 **v3 口径**（15 工具），前提是退化曲线真读数先出来（在途任务）。

---

## 按五个维度对照

### 1. MLOps / 评测岗叙事强度

| | A（现状） | B（v4） | C（v3） |
|---|---|---|---|
| 可讲的完整闭环 | 数据冻结→teacher→SFT→配对评测→版本化门禁→封存判定→单卡部署，**每一环都有读数** | 同样的闭环讲第二遍，只是工具面更宽 | 同左，且「15 工具退化曲线」本身是一条独立叙事线 |
| 岗位关键词覆盖 | 后训练、评测、门禁、部署 | +多工具泛化、跨场景扩展 | +工具数 scaling、能力-规模权衡 |
| 与竞品项目的区分度 | 高（封存纪律 + 预注册判读是稀缺点） | 中——泛化实验市面常见 | 中高（退化曲线若真做出来） |

**判断**：A 的叙事强度不弱于 B/C。这个项目的稀缺点从来不是工具数量，而是
**评测的可信度工程**（封存集、预注册、fail-closed 门禁、绝对门）。迁移不会增加
稀缺点，只会稀释完成度。

### 2. 证据链深度

| | A | B | C |
|---|---|---|---|
| 封存 holdout | 有（7 次观测的台账 + 判定） | **必须重建**（新封存集 = 新测量） | 同左 |
| 配对证据 | 完整（dev + sealed 逐任务） | 重建 | 重建 |
| OOD 门 | v1.2/v1.3 已就绪 | 需在 v4 素材上重新登记版本并冻结 | 同左 |
| 退化曲线 | 读数作废（在途重跑） | 不适用（5 工具只有 2 个断点） | **是其核心产出** |

### 3. 面试可解释性

- A：一句话讲清「为什么 3 工具敢说可信」——因为判定纪律，不是因为场景多。
- B：要回答「为什么换了口径」——答案是「为了更宽的工具面」，但追问「v1 的判定
  还算数吗」时，答案是「口径不同不可比」，这会**弱化**已有 GO 的叙述。
- C：同样的问题 + 「15 工具上你的模型表现如何」——在退化曲线读数出来之前
  无以对答，**这正是 R10 读数作废教训的重复风险**：先迁移、后跑数、数不好看。

### 4. 全部成本

| 项 | B（v4） | C（v3） |
|---|---|---|
| 新 dataset_version 冻结 | 是（v4 冻结于 2026-08-22，但**发布口径的冻结**需重新走） | 是 |
| teacher 采集 | 已有 474 accepted（可复用，需验配对前提） | 需重新评估 |
| 新封存集 | 必须新造（观测不可复用） | 同左 |
| base/candidate 全量重跑 | GPU 数日 | 同左 + 5 断点曲线 |
| 简历/文档/治理测试同步 | 全量 | 全量 + 曲线 |
| **合计** | ≈ 一次完整 R2–R6 循环的 60–70% | ≥ 100% |

### 5. 风险

- 共同风险：历史读数不可比——**已有 GO（v1 口径）不能带到新口径上引用**，
  迁移期间简历上的核心数字处于「新旧口径都不完整」的空窗。
- B 特有：v4 dev 0.95 / OOD v4 0.8917 / pv2——OOD 违规 2 次在 v1.3 绝对门
  （0 容忍）下**直接 NO-GO**；迁移大概率换来一个 NO-GO 判定写进台账。
- C 特有：退化曲线重跑依赖 gpu-5090 恢复（环境故障，无 ETA）；在装置读数出来前
  做迁移决策违背本项目「先装置后读数」的纪律（LOG-20260827-01 的教训）。

---

## 结论与建议

**建议：不迁移（维持选项 A），把 v3/v4 作为探索性结论保留在简历的辅助位置。**

理由按权重排序：

1. **简历质量由证据链深度决定，不由工具面宽度决定。** 本项目的差异化是评测可信度
   工程；A 拥有全部稀缺点，迁移会用 60–100% 的一次完整循环成本换一个稀释版本。
2. **B 在 v1.3 门禁下大概率 NO-GO**（OOD v4 pv2 > 0）——花大成本买一个写进台账的
   判负，直接损害简历叙事。
3. **C 的前提（真退化曲线读数）还不存在**；在途任务（E2）完成前做决策是把
   LOG-20260827-01 的教训再犯一遍。
4. 若未来要迁移，**正确的触发条件**是：(a) 退化曲线真读数显示 15 工具无显著退化
   或 (b) 用户确定目标岗位明确需要多工具叙事。届时按「新 dataset_version 全价
   重建」立项，而不是在现有闭环上打补丁。

**本分析不改变任何现有冻结契约与在途任务优先级。**
