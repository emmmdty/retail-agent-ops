# 6.2 废弃数字与归因的残留

## 任务

找出所有已作废的数字、已推翻的归因、已修正的结论，在项目各处是否仍有残留引用。

## 需要读取的文件

- 全项目搜索已知废弃内容：
  - "退化曲线" / "tool_count" / "0.45" / "0.70"（R10 作废读数）
  - "2 次政策违规"（修正为 2-7 次）
  - "措辞增强的确定代价"（归因被推翻）
  - "120/120"（应与 OOD 成对出现）
  - R6 的旧候选 sft-006 读数

## 找什么

1. **README 中是否还有废弃数字**：搜索上述关键词。

2. **简历中是否还有废弃数字**：搜索上述关键词。

3. **面试材料中是否还有废弃归因**：搜索"措辞增强"、"确定代价"等。

4. **代码注释中是否还有废弃逻辑**：搜索相关注释。

5. **测试中断言是否引用了废弃数字**：搜索测试中的硬编码数字。

6. **AGENTS.md 中的摘要是否已更新**：AGENTS.md 引用了多次数字，是否都是最新版本？
