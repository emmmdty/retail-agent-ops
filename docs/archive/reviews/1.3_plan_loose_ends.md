# 1.3 阶段执行计划中的未闭环项

## 任务

找出 EXECUTION_PLAN 中标注"已完成"但实际有未完成子项、或标注"已做"但证据不足的地方。

## 需要读取的文件

- `docs/EXECUTION_PLAN.md` — 重点看 R5、R6、R10 的"未做及原因"和"更正记录"

## 找什么

1. R5 标注"已完成"但明确写了 5 条执行目标做了 4 条——未做的那条（跨模型/商业 API 参考上限）是否有替代方案？还是直接跳过了？

2. R10 退化曲线作废后，是否明确了"要拿到真的退化曲线必须重跑"？这个重跑是否已安排？还是无限期搁置？

3. R6 的"自变量不纯"（sft 行数和梯度步数同时改变）——这个问题是否有后续计划分离？还是接受为已知限制？

4. 各阶段的"验收目标"是否都有对应证据？还是有验收目标写了但没证据支撑？

5. R4.5 的"阈值一个字不改"——这些锁死的阈值在代码中是否有测试保护？测试是否真的能防止修改？
