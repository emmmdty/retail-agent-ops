# 2.1 Agent 执行循环的边界问题

## 任务

审查 Agent 的实际执行代码，找出边界情况下的 bug、未处理异常、和潜在的死循环/崩溃。

## 需要读取的文件

- Agent 执行循环代码（如 `agent.py`、`runner.py`、`executor.py`）
- tool parser 代码
- 提示词模板

## 找什么

1. **最大步数边界**：达到最大步数时如何退出？是否有兜底输出？还是直接抛异常？

2. **工具调用失败处理**：工具返回错误时 Agent 的行为是什么？是重试、跳过、还是崩溃？重试次数有限制吗？

3. **格式解析失败**：LLM 输出的工具调用格式不对时（缺少参数、JSON 格式错误、调用不存在的工具），parser 的行为是什么？是否有 fallback？

4. **空输出处理**：LLM 返回空内容或纯文本（不含工具调用）时，系统如何处理？

5. **token 超限**：多步执行时上下文长度超出模型限制怎么办？是否有截断或摘要机制？

6. **并发安全**：如果多个请求同时调用同一个 Agent 实例，是否有竞态条件？
