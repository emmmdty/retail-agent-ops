# 2.2 Tool Parser 与工具执行的 Bug

## 任务

审查工具解析和工具执行的代码，找出解析错误、执行异常、和逻辑漏洞。

## 需要读取的文件

- tool parser 代码
- 工具执行代码
- 工具 schema 定义
- 相关测试

## 找什么

1. **解析正则的鲁棒性**：如果 LLM 输出中工具调用的参数包含特殊字符（引号、括号、换行），正则是否能正确处理？

2. **参数类型校验**：解析出的参数是否做了类型校验？比如期望 int 但收到 string 时怎么处理？

3. **工具执行超时**：工具调用是否有超时机制？如果工具执行卡住，Agent 会永远等待吗？

4. **工具执行的副作用**：退款工具真的会退款吗？还是只是返回模拟结果？如果有副作用，测试中如何隔离？

5. **非法工具调用检测**：声称有检测——检测逻辑在哪？是检查工具名是否存在，还是检查参数是否合法？

6. **R10 退化曲线的空转 bug**：tool_count 参数未生效，5 个断点产出相同任务——这个 bug 的根因代码在哪？修复是否完整？
