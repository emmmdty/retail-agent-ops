# 7.1 代码中的 TODO/FIXME/潜在 Bug

## 任务

搜索项目代码中的 TODO、FIXME、HACK、临时修复、和潜在的运行时错误。

## 需要读取的文件

- 全项目搜索 TODO/FIXME/HACK/XXX/WARNING
- `src/veritool_rl/` 下的核心代码
- `tests/` 下的测试代码

## 找什么

1. **TODO/FIXME 清单**：列出所有 TODO/FIXME，标注优先级和是否影响核心功能。

2. **硬编码的路径/凭据**：是否有硬编码的绝对路径、API key、模型路径？

3. **未处理的异常**：搜索 `except Exception`、`except:`、空的 except 块——是否有吞掉异常的情况？

4. **未使用的导入/变量**：ruff 或 mypy 是否报告过警告？当前警告数量是多少？

5. **测试中的 mock/patch**：测试中是否有过多的 mock 导致测试失去意义？

6. **配置文件的一致性**：pyproject.toml、uv.lock、requirements 之间的依赖版本是否一致？
