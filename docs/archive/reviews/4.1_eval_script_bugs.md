# 4.1 评测脚本的 Bug

## 任务

审查评测相关代码，找出评测脚本中的逻辑错误、配置问题、和不可靠行为。

## 需要读取的文件

- 评测脚本代码
- 评测配置文件
- 评测结果生成代码
- 测试中对评测的覆盖

## 找什么

1. **评测集加载逻辑**：评测脚本是否真的加载了指定版本的评测集？版本选择逻辑是否正确？

2. **结果持久化**：评测结果是否正确写入了报告文件？报告格式是否与 schema 一致？

3. **评测与训练的配置对齐**：评测时用的工具列表、政策规则是否与训练时一致？如果不一致，差异是否有记录？

4. **评测集的版本切换**：从 v1 切到 v2 再切到 v3 时，是否有残留的旧版本配置影响新评测？

5. **评测的超时和重试**：评测中的工具调用是否有超时？如果某个任务超时，是算失败还是跳过？

6. **评测结果的缓存**：是否有缓存机制导致用了旧结果？缓存失效逻辑是否正确？
