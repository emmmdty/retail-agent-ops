# 5.1 训练配置与流程问题

## 任务

审查 QLoRA-SFT 训练的配置管理、执行流程、和产物管理，找出配置错误和流程风险。

## 需要读取的文件

- 训练脚本
- 训练配置文件（YAML/JSON/TOML）
- `docs/EXECUTION_PLAN.md` R3、R4、R6
- `docs/REBUILD_VERIFICATION.md`

## 找什么

1. **配置管理**：训练参数（lr、epochs、LoRA rank/alpha/target、batch size）在哪里管理？是否有配置验证？

2. **训练不可复现的根因**：同 seed 重跑产出逐位不同的 adapter——是代码问题（如 random seed 没设对）还是框架行为（如 CUDA non-determinism）？如果是后者，文档中是否明确说明？

3. **checkpoint 管理**：训练产出的 checkpoint/adapter 是否有版本管理？是否可能被意外覆盖？

4. **显存管理**：单卡 4090 上训练 4B 模型的显存占用峰值是多少？是否有 OOM 风险？

5. **训练中断恢复**：如果训练中断（如 GPU 故障），是否能从 checkpoint 恢复？还是必须重跑？

6. **训练日志**：训练过程的 loss 曲线、grad norm 等指标是否记录？是否有训练不稳定的迹象？
