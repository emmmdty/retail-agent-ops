# 7.3 配置管理与依赖风险

## 任务

审查项目的配置管理、依赖管理、和环境管理，找出配置风险和依赖冲突。

## 需要读取的文件

- `pyproject.toml`
- `uv.lock`
- 配置文件（YAML/JSON/TOML）
- CI 配置（如有）
- `scripts/ci/`

## 找什么

1. **依赖版本锁定**：关键依赖（transformers、peft、vllm）的版本是否锁定？版本升级是否可能引入兼容性问题？

2. **配置漂移**：训练配置、评测配置、发布配置是否在同一处管理？是否有配置漂移（同一参数在不同地方值不同）？

3. **环境变量依赖**：项目依赖哪些环境变量（如 `TEACHER_LLM_*`）？缺失时的错误提示是否清晰？

4. **CI 与本地的一致性**：CI 中跑的测试与本地是否一致？CI 是否真的在干净环境中运行？

5. **发布产物的完整性**：发布时需要哪些产物（模型权重、配置、manifest）？是否都有完整性校验？

6. **`git diff --check` 的有效性**：这个门禁是否真的能检测到问题？它检查的是什么？
