# 1.2 文档声明与代码实现不符

## 任务

找出文档中声称的功能、接口、流程，在代码中要么不存在、要么实现与描述不一致的地方。

## 需要读取的文件

- `docs/PRODUCT_BRIEF.md` — 声称的接口 build/evaluate/release/serve
- `docs/EXECUTION_PLAN.md` — 声称的各阶段交付物
- CLI 入口代码（如 `__main__.py`、`cli.py`、`click`/`typer` 定义）
- `src/veritool_rl/` 下的核心模块

## 找什么

1. PRODUCT_BRIEF 声称稳定接口是 `build`、`evaluate`、`release`、`serve`——这四个 CLI 命令是否都真的存在？参数是否与文档一致？

2. 声称"每次运行必须输出固定配置、commit、manifest 哈希、逐任务轨迹、失败分类"——输出格式是否与文档描述一致？是否有字段缺失？

3. R4.5 声称"业务政策外置为可执行规则"——实际是外置配置还是硬编码？

4. R4.5 声称"退款幂等键"——实现代码在哪？是否真的防止了重复退款？

5. R4.5 声称"独立 guardrail 层与注入评测"——评测代码和 guardrail 代码是否真的存在？

6. 声称 907 tests passed——当前 `pytest` 实际能跑过多少？
