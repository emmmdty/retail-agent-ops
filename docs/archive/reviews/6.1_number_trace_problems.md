# 6.1 数字追溯中的问题

## 任务

逐条追溯简历中的数字到原始实验记录，找出不可追溯、口径错误、或已过时的数字。

## 需要读取的文件

- `docs/RESUME_EVIDENCE.md`
- `docs/HOLDOUT_LEDGER.md`
- `docs/EXECUTION_PLAN.md`
- `docs/REBUILD_VERIFICATION.md`
- `docs/R9_PHASE_B_RESULTS.md`

## 找什么

1. **每个数字的来源文件**：简历上的每个量化指标，能否追溯到具体的实验记录？追溯不到的就是风险。

2. **口径错误**：同一个指标在简历和原始记录中是否口径一致？比如简历写的"120/120"实际上来自 dev 而非 holdout。

3. **过时数字**：简历中是否有引用了已被修正或作废的旧数字？

4. **区间表述的一致性**：dev "58-60/60"、holdout "113-117/120"——这些区间是否在所有文件中一致？

5. **flight_ops 的数字归属**：跨域 GO 是 teacher 模型的结果还是 SFT 模型的结果？简历中是否写清楚了？

6. **R9 的数字引用**：sft-003 的 OOD 数字是否出现在简历中？如果出现了，与 sft-008 的数字是否可比？
