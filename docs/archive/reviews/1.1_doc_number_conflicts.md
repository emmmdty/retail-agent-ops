# 1.1 文档间数字与结论矛盾

## 任务

找出项目各文档之间在数字、结论、状态描述上的不一致。

## 需要读取的文件

- `docs/PRODUCT_BRIEF.md`
- `docs/EXECUTION_PLAN.md`
- `docs/RESUME_EVIDENCE.md`
- `docs/INTERVIEW_PREP.md`
- `docs/HOLDOUT_LEDGER.md`
- `docs/REBUILD_VERIFICATION.md`
- `README.md`
- `README.en.md`

## 找什么

同一指标在不同文件中的数字是否一致。比如：
- dev 成功率在简历、README、面试材料、执行计划中写的是否同一个数？
- holdout 观测结果在 HOLDOUT_LEDGER 和 EXECUTION_PLAN 中是否一致？
- 政策违规次数的不同表述（2次 vs 2-7次 vs 11→2）是否在所有文件中都已同步？
- 阶段状态在 EXECUTION_PLAN 的总览表和各阶段详情中是否一致？
- 退化曲线作废这个事实在所有引用处是否都已标注？

对每个不一致，标注两个文件的具体位置和差异内容。
